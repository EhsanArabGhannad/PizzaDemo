# Pizza Knight Front-end Demo

A responsive, dependency-free HTML/CSS/JavaScript demo for a proposed Pizza
Knight website redesign.

## Run locally

Node.js is the only requirement; no packages need to be installed. From the
project directory, run:

```powershell
npm start
```

Then open <http://localhost:5500>.

Stop the server with `Ctrl+C`.

You can also use the **Live Server** extension in VS Code and open `index.html`
with it.

## Current scope

This first step contains only the responsive project foundation. Planned demo
features include:

- Homepage
- Sample menu
- Pizza customisation
- Basket
- A visible 50p service fee

This is a demonstration only; it will not process real orders or payments.
